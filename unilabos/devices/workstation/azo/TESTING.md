# 偶氮工站设备调试指南

本文档介绍如何使用独立的调试脚本测试偶氮工站的各个设备。

## 调试脚本列表

1. **test_pump.py** - 蠕动泵调试
2. **test_temperature.py** - 温控器调试
3. **test_spectrometer.py** - 光谱仪调试

所有脚本都是独立运行的，不需要启动Uni-Lab系统。

---

## 1. 蠕动泵调试 (test_pump.py)

### 功能
- 控制两个蠕动泵的转速
- 支持正转、反转、停止
- 实时查看泵的状态

### 使用方法

```bash
# 默认串口 COM3，波特率 38400
python test_pump.py

# 指定串口和波特率
python test_pump.py COM3 38400
```

### 命令格式

```
>>> 100 150      # 泵A转速100rpm，泵B转速150rpm
>>> 0 0          # 停止两个泵
>>> -50 100      # 泵A反转50rpm，泵B正转100rpm
>>> status       # 查看当前状态
>>> stop         # 停止所有泵
>>> q            # 退出
```

### 注意事项

1. **串口配置**：确保串口号正确（Windows: COMx, Linux: /dev/ttyUSBx）
2. **通信参数**：波特率38400，数据位8，校验位N，停止位1
3. **Modbus站号**：泵A站号5，泵B站号6
4. **寄存器地址**：PA-53 (地址53，Modbus地址=40001+53=40054)
5. **数据格式**：int16，<0反转，=0停止，>0正转
6. **转速范围**：根据实际泵的规格设置合理的转速范围

## 2. 温控器调试 (test_temperature.py)

### 功能
- 设置目标温度
- 读取实际温度
- 查看温度偏差
- 停止加热

### 使用方法

```bash
# 默认串口 COM3，波特率 38400
python test_temperature.py

# 指定串口和波特率
python test_temperature.py COM3 38400
```

### 命令格式

```
>>> 25.5         # 设置目标温度为25.5°C
>>> 60           # 设置目标温度为60°C
>>> read         # 读取当前温度
>>> stop         # 停止加热
>>> status       # 查看状态
>>> q            # 退出
```

### 注意事项

1. **通信参数**：波特率38400，数据位8，校验位N，停止位1
2. **Modbus站号**：温控器站号1
3. **寄存器地址**：
   - 目标温度：4096 (0x1000)，Modbus地址=40001+4096=44097
   - 实际温度：4098 (0x1002)，Modbus地址=40001+4098=44099
   - 输出使能：4352 (0x1100)，uint16，0=关闭输出，1=打开输出
4. **温度数据格式**：int32 (大端序)，单位/100000 (例如2500000表示25.00000°C)
5. **温度范围**：0-100°C（可在代码中修改）
6. **温度精度**：0.00001°C

## 3. 光谱仪调试 (test_spectrometer.py)

### 功能
- 采集光谱数据
- 保存光谱（CSV/JSON格式）
- 绘制光谱曲线
- 设置积分时间和平均次数

### 使用方法

```bash
# 默认配置
python test_spectrometer.py

# 指定DLL路径和设备索引
python test_spectrometer.py <dll_path> <device_index>
```

### 命令格式

```
>>> acquire      # 或 'a' - 采集一次光谱
>>> save         # 保存最后一次采集的光谱（自动命名）
>>> save data.csv # 保存到指定文件
>>> plot         # 绘制光谱曲线
>>> set_time 100 # 设置积分时间为100ms
>>> set_avg 5    # 设置平均次数为5
>>> status       # 查看状态
>>> q            # 退出
```

### 注意事项

1. **依赖库**：
   - pythonnet：用于调用.NET SDK
   - matplotlib：用于绘图（可选）
   
   安装方法：
   ```bash
   pip install pythonnet matplotlib
   ```

2. **DLL路径**：默认路径为 `./光谱仪/Python4CyUSB/dlls/Ideaoptics.USB.SDK.dll`

3. **设备连接方式**：光谱仪在设备管理器中显示为 `IdeaOptics USB Device`，不是COM串口

4. **模拟模式**：如果SDK加载失败，会自动进入模拟模式，生成随机光谱数据

5. **数据格式**：
   - CSV：包含元数据和波长-强度数据
   - JSON：完整的数据结构

## 常见问题

### 1. 泵或温控器串口连接失败

**问题**：`✗ 串口连接失败: [WinError 2] 系统找不到指定的文件。`

**解决方法**：
- 检查串口号是否正确
- 在设备管理器中查看实际的COM口号
- 确保串口没有被其他程序占用
- 检查RS485/USB转串口驱动是否已安装

### 2. 光谱仪SDK加载失败

**问题**：`✗ SDK加载失败: Could not load file or assembly`

**解决方法**：
- 确认pythonnet已安装：`pip install pythonnet`
- 检查DLL文件路径是否正确
- 确认设备管理器中能看到 `IdeaOptics USB Device`
- 确认 IdeaOptics USB 驱动已安装，而不是把光谱仪当COM口连接
- 确认.NET Framework已安装（Windows）
- 使用模拟模式进行测试

### 3. Modbus通信无响应

**问题**：发送命令后没有响应

**解决方法**：
- 检查波特率、数据位、校验位、停止位配置
- 确认Modbus从站地址正确
- 使用串口调试工具验证硬件连接
- 检查CRC校验是否正确

### 4. 温度读取异常

**问题**：读取的温度值异常（如负数或超大值）

**解决方法**：
- 检查寄存器地址是否正确
- 确认数据格式（int32，大端序）
- 查看原始响应数据（十六进制）
- 参考设备手册确认通信协议

## 调试流程建议

### 第一步：测试蠕动泵

1. 连接RS485串口
2. 运行 `python test_pump.py`
3. 测试命令：
   ```
   >>> 50 50      # 低速测试
   >>> status     # 查看状态
   >>> 0 0        # 停止
   ```

### 第二步：测试温控器

1. 确保与泵共享同一个RS485串口
2. 运行 `python test_temperature.py`
3. 测试命令：
   ```
   >>> 30         # 设置接近室温的温度
   >>> read       # 读取实际温度
   >>> status     # 查看状态
   >>> stop       # 停止加热
   ```

### 第三步：测试光谱仪

1. 连接光谱仪USB线，并确认设备管理器中显示 `IdeaOptics USB Device`
2. 运行 `python test_spectrometer.py`
3. 测试命令：
   ```
   >>> status     # 查看设备信息
   >>> a          # 采集光谱
   >>> save       # 保存数据
   >>> plot       # 查看曲线
   ```

### 第四步：联合测试

在确认各设备单独工作正常后，可以：
1. 同时运行泵和温控（共享串口）
2. 测试在不同温度和流速下采集光谱
3. 验证数据采集的稳定性
