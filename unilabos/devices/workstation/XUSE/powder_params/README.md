# 粉末加样参数库

此目录存放“多种加粉”动作使用的旧版加样参数 `.xlsx` 文件，可按需要建立子目录。

- 默认以文件名（不含 `.xlsx`）匹配加粉清单中的“加粉名称”。
- 文件名不匹配时，会读取 `单值参数` sheet 中的 `粉末名称` 作为备用匹配。
- 参数文件结构与 `../templates/加样参数模板.xlsx` 相同。
- 多种加粉执行时，清单中的“加粉名称”和“重量”会分别覆盖参数文件里的
  `粉末名称` 和 `加样_重量`，其余参数保持文件原值。
- 同一名称只能对应一个文件，否则动作会在写入 PLC 前报错。

多种加粉清单是独立的 `.xlsx` 文件。每个球磨罐使用一个 sheet，sheet 名建议直接写
`1`~`32`；每个 sheet 的表头至少包含 `加粉名称`、`重量` 两列，按表格行顺序执行。
