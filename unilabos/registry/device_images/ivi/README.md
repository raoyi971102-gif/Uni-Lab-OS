# IVI 设备图片

打开 `gallery.html` 可离线浏览；`manifest.json` 为机器可读的资产和逐型号索引，`model-index.csv` 含全部 699 个注册型号及缺图记录。`assets/` 保留来源图片原始字节。

- `model_source_image`：来源明确对应具体型号的图片，不表示本项目实机拍摄或测试。
- `series_reference`：同代产品系列参考图；型号、通道数、面板和配置以厂商资料为准，不保证完全一致。
- `missing`：本轮没有取得审核通过的图片；保持缺图，不用其他代产品或品牌标识填充。

注册表 `icon` 使用本仓库 community 分支的 raw 图片地址；`image_evidence` 同时记录仓库内路径、来源、匹配类型、说明和 SHA-256。离线环境可以直接使用本目录图片，或部署到自身静态资源服务后替换 icon 地址。图片不影响驱动白名单、兼容等级或已验证状态。
